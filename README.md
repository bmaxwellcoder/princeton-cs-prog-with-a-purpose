This repository contains my solutions and implementations for the Princeton University's "Computer Science: Programming with a Purpose" course on Coursera. The course provides a comprehensive introduction to computer science and programming using Java.

## Course Overview

This course covers fundamental programming concepts and techniques, focusing on:
- Basic programming concepts and data types
- Control flow and loops
- Arrays and data structures
- Input/output operations
- Functions and libraries
- Recursion and advanced programming techniques
